# Balikbayan Protocol

A cyberpunk time-jump console: lock in your birthdate, ride your life timeline, and drop into any year back to it for a dossier of Philippine politics, showbiz, technology, the era's communication device, and its street-level trend.

This folder is the Android app wrapper (via [Capacitor](https://capacitorjs.com)) around the web app in `www/`, ready to build into a Play Store submission.

**Start here:** [`SETUP_GUIDE.md`](./SETUP_GUIDE.md) — the complete path from this folder to a live Play Store listing, including the GitHub Actions build pipeline, signing, privacy policy hosting, and store listing copy.

Ready-to-use assets already generated: app icon, adaptive icon, feature graphic, and phone screenshots in `assets/`; store listing copy in `PLAY_STORE_LISTING.md`; privacy policy in `docs/index.html`.
